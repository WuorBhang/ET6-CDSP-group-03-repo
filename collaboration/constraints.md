# 📊 Data Science Project Constraints

Welcome to our data science project! This document outlines the key constraints
 that will guide our work and ensure a successful and timely delivery.

---

## 🚧 Project Boundaries

To keep our project focused, efficient, and aligned with best practices, we’ve
 established the following constraints:

---

### 🌐 External Constraints

These are non-negotiable rules we must follow:

1. **Deadline** 🕒  
   - Complete all phases (data cleaning, analysis, modeling,
 evaluation) by **12th September 2025**.

2. **Model Validation** ✅  
   - Final model must pass at least **4 evaluation benchmarks**, such as:
     - Accuracy
     - Precision
     - Recall
     - F1-score
     - MAE/MSE/RMSE (for regression)

3. **Libraries** 📚  
   - Use only standard Python libraries including:
     - `pandas`
     - `numpy`
     - `scikit-learn`
     - `matplotlib`
     - `seaborn`
     - `pytest` for testing

4. **Version Control** 🔗  
   - Use **Git and GitHub** with:
     - Protected `main` branch
     - Pull Request (PR) reviews before merging

5. **Packaging** 📦  
   - Package the data pipeline or module using **`setup.py`** for
   reproducibility and deployment.

---

### 🏠 Internal: Involuntary Constraints

These are limitations based on our environment and time:

- **Daily Time Commitment** ⏳  
  - Each team member must commit at least **2 hours per day**.

- **Hardware Requirements** 💻  
  - All members must use a system capable of running **Python 3.10.0+**.

---

### 🤝 Internal: Voluntary Constraints

Agreements we've made as a team to improve quality and collaboration:

#### 🛠️ Language & Tools

- **Language**: Python (version 3.10.0+)
- **File Naming Conventions**:
  - Scripts: `lowercase_with_underscores.py` (e.g., `data_cleaning.py`)
  - Test files: `test_<module_name>.py` (e.g., `test_data_cleaning.py`)

#### 📊 Workflow

- Follow this structured data science pipeline:
  - Data Collection → Data Cleaning → EDA → Modeling → Evaluation → Deployment

#### 📋 Collaboration Tools

- **Task Management**: GitHub Issues & Projects
- **Communication**: Slack & WhatsApp

---

### 🎉 Let’s Stick to the Plan

These constraints will help us stay organized, efficient, and on track. Let’s
 collaborate and deliver a powerful data science solution! 🚀
